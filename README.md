# Digital VLSI Design (DVD) — Part A

## Overview
This repository contains the Verilog RTL implementation and testbench for Part A.

## Source Files
- `rtl/full_adder.v` — Full-adder module.
- `rtl/mult_array.v` — Multiplier array implementation.
- `tb/tb_mult.v` — Testbench for functional verification.

## Functional Verification
The testbench checks the multiplier outputs against expected results.

## Tools
- Verilog
- Icarus Verilog (`iverilog`)
- VVP simulator
